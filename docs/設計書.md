# タグラグビー作戦アプリ 設計書（v0.2）

> 2026-10-28 追記：試作1の実装で決まったこと・変わったこと（オリジナル作戦、作戦の矢印、人形アニメなど）は `docs/実装状況.md` にまとめています。食い違うときは `実装状況.md` を優先してください。

作成日：2026-10-25（v0.2：保存先・端末・名簿などの決定を反映）
対象：第3学年 体育「かわして つないで トライ！」（タグラグビー、8時間扱い）
関連資料：学習指導案、学習カード、作戦カード5種、作戦ボード（すでに作成ずみ）

## 1. このアプリでできること

紙の学習カード・作戦カード・作戦ボードを1つにまとめ、iPadで使えるようにする。

1. **作戦ボード**：5つの作戦カードから1つ選んで貼り、メンバーの名前をコート上で動かして立ち位置を決める。守り2人のコマも置ける。
2. **作戦アニメ**：作戦カードの図の子どもとボールが動き、作戦の動きを確かめられる。
3. **撮影と振り返り**：ゲームを撮影し、早送り・スローで見返したり、作戦アニメと並べたり、止めた画面に書き込んだりできる。
4. **学習カード**：一人一人が、めあて、できた番号への○、「できたこと」「次にやりたいこと」を入力し、PDFで提出する。

## 2. 決まったこと

| 項目 | 決定 |
| --- | --- |
| 作り方 | Webアプリ。ブラウザで開いて使う |
| 動かす端末 | まずiPad（Safari）。あとでWindowsのThinkPad（Edge）でも同じものを使う |
| ホーム画面への追加 | **できない前提**で作る（Safariのタブで開いて使う） |
| カメラ | Safariのカメラ利用は許可できる見込み（最初の試作で確認） |
| 端末の使い方 | 作戦ボード・撮影はチームで1台（監督・撮影係が持つ）。学習カードは1人1台 |
| 保存先 | **端末の中だけ**。外のサーバーやクラウドには送らない |
| チーム・名前 | 先生が先に登録する。Excelからのコピー＆ペーストか、CSVファイルの読み込みで入れる |
| 1チームの人数 | 5人を基本にし、3〜7人などに変えられるようにする |
| 名前の表示 | 本名（フルネーム）か名字だけかを、先生メニューで切り替える |
| 作戦の動画 | 作戦カードの図が動くアニメ。ネット動画は使わない（ネットがなくても見られる） |
| 学習カード | アプリに入れる。PDFにして提出する |
| 守りのコマ | 置く（相手の守り2人） |
| 振り返りの動画 | 早送り・スロー再生／使った作戦と日付を一緒に保存／作戦アニメと並べて見る／止めて書き込み |
| 動画を消す時期 | 学期の終わり（先生メニューから一括で消す） |
| 大型テレビ | 基本は先生の端末をつなぐ |

## 3. 授業の流れと画面の対応（第3〜7時）

| 授業の流れ（指導案） | 使う画面 | 端末 |
| --- | --- | --- |
| めあてを立てる | 学習カード（めあて） | 1人1台 |
| 作戦タイム① | 作戦ボード → 作戦アニメで確認 | チーム1台 |
| トライゲーム① | 撮影 | チーム1台（撮影係） |
| 作戦タイム② | 振り返り動画（並べて見る・書き込み）→ 作戦ボードで立て直し | チーム1台 |
| トライゲーム② | 撮影 | チーム1台 |
| 全体で共有 | 先生の端末で作戦アニメや作戦ボードを大型テレビに映す | 先生の端末 |
| ふり返り | 学習カード（番号に○、できたこと・次にやりたいこと） | 1人1台 |

全体で共有するときに子どもの動画を映したい場合は、そのチームの端末から動画を書き出して先生の端末に渡すか、チームの端末を一時的にテレビにつなぐ（10章で相談）。

## 4. 画面一覧

```
ホーム
├─ 先生メニュー（合言葉で入る）
│   ├─ 名簿の登録（コピー＆ペースト／CSV）
│   ├─ 表示の設定（本名・名字、人数、ふりがな）
│   ├─ 名簿をほかの端末に写す
│   └─ データの書き出し・消去（学期末の一括消去）
├─ チームを選ぶ
│   ├─ 作戦ボード
│   │   └─ 作戦アニメ
│   ├─ 撮影
│   └─ 振り返り動画（一覧 → 再生）
└─ 学習カード（自分の名前を選ぶ → PDFで提出）
```

### 4.1 ホーム
- 大きなボタン3つ：「チームで使う」「学習カード」「先生」。
- 3年生が迷わないように、文字は大きく、ひらがな中心にする。
- Safariのタブで開くので、URLを短くし、教室にQRコードを貼っておけばすぐ開けるようにする。

### 4.2 先生メニュー：名簿の登録
- **コピー＆ペースト**：Excelで「番号・名字・名前・チーム」の4列を選んでコピーし、アプリの入力欄に貼り付ける。列の区切り（タブ）を読み取って一覧にする。
- **CSVファイル**：同じ4列のCSVを読み込む。
- 読み込んだあと、確認の表を出す。チーム名・チームの色・メンバーは、その表の上で直せる。
- **人数**：チームごとの人数は名簿のとおり（5人が基本。4人や6人のチームがあってもよい）。
- **表示の設定**：コマや学習カードに出す名前を「本名（例：さなだ ひろゆき）」か「名字だけ（例：さなだ）」から選ぶ。同じ名字の子がいるときは、名前の1文字目を自動で足す（例：さなだ ひ）。
- **ほかの端末に写す**：保存先が端末の中だけなので、名簿は1台で作ってから各端末に写す。次の2つの方法を用意する。
  - 名簿のファイルを書き出して、AirDropや校内のファイル共有で渡す。
  - 画面に出したQRコードを、ほかの端末のカメラで読む。
- 合言葉（4けたの数字など）で、子どもが先生メニューに入れないようにする。

### 4.3 作戦ボード（中心の画面）
- **コート**：紙の作戦ボードと同じ。トライゾーン、スタートライン、守りのスタートライン、縦に4つのレーン（1〜4）。
- **作戦カードを貼る**：画面の横に5枚のカードを並べ、タップした1枚がボードの「カードを貼る場所」に入る。
- **名前のコマ**：
  - メンバーの名前が入った丸いコマを、指でドラッグして動かす。
  - 最初は1〜4のスタート位置に並び、監督と、攻めに出ない人のコマはコートの外に置く。
  - 人数が5人でないチームでも、コートに出すのは攻め4人と決めておき、残りは外に置く。
  - 作戦カードを選ぶと、「作戦の形に並べる」ボタンでカードの図の位置へ自動で動く。
- **守りのコマ**：相手チームの色で2つ。自由に動かせる。
- **ボール**：ひし形のコマ。持っている子のコマにくっつけられる。
- **線を書く**：「走る（実線）」「パス（点線）」をペンで書ける。全部消すボタンもつける。
- **保存**：今の並びを「今日の作戦」として保存する（撮影した動画と結び付ける）。

### 4.4 作戦アニメ
- 作戦カードの図と同じコートで、1〜4の子どもとボールが動く。
- 再生、一時停止、「もう一回」、ゆっくり再生（0.5倍）。
- 動きの区切りに短い字幕を出す（例：「②と③が ×に走る」→「すれちがうときに パス！」）。
- 作戦ボードで並べた名前で動かす「チームの名前で見る」切り替えをつける。
- アニメのデータは作戦ごとに「誰が、何秒後に、どこへ動くか」の一覧で持つ（8章）。新しい作戦も足しやすい形にする。

### 4.5 撮影
- iPadのカメラで動画を撮る。撮影係が大きな赤いボタンで開始・停止する。
- 撮った動画には、自動で次の3つを付ける。
  - チーム
  - 日付と何時間目か
  - そのとき作戦ボードに貼っていた作戦
- 長さの目安を表示し、1本10分程度で自動的に止まるようにする（容量を使いすぎないため）。
- 端末の空き容量が少ないときは、撮影の前に知らせる。

### 4.6 振り返り動画
- **一覧**：チームの動画が日付・作戦つきで並ぶ。
- **再生**：0.25倍・0.5倍・1倍・2倍・4倍で再生する。タイムラプスの代わりに、早送りで全体を見てスローで場面を見る。
- **並べて見る**：左に撮った動画、右にその作戦のアニメを並べる。
- **止めて書き込み**：一時停止した画面に、指で矢印や丸を書く。書き込んだ画面を写真として保存できる。
- **動画を書き出す**：先生が残したい動画は、写真アプリやファイルに保存できるようにする（7章の、データが消えたときへの備え）。

### 4.7 学習カード（1人1台）
- 自分の名前を選んで開く。
- **単元のめあて**：最初の時間に入力する。
- **毎時間の記録**：
  - めあて（前の時間の「次にやりたいこと」を下に表示して、参考にできる）
  - できた番号に○（○1〜5、□1〜3、◇1〜3をタップ。目指す姿の文はタップで表示）
  - 「できたこと」「次にやりたいこと」
  - 入力は、キーボード、手書き、音声入力のどれでもよい。
- 1〜8時間目の記録を一覧で見られる。
- **PDFで提出**：
  - 「PDFにする」ボタンで、紙の学習カードと同じ見た目のPDF（A4）を作る。
  - ファイル名は自動で付ける（例：`タグラグビー_3年1組_05_さなだ.pdf`）。
  - できたPDFは、iPadの共有ボタンから学校で使っている提出先（課題の提出箱など）に出す。
- 単元の途中でも、毎時間の終わりにPDFを出しておけば、データが消えたときにも記録が残る（7章）。

## 5. 画面の作りの約束

- 文字は大きく、ひらがな中心。3年生の漢字にはふりがなをつける（設定で消せる）。
- ボタンは大きく（指でおしやすい44px以上）、外で使うことを考えて明るい画面でも見やすい色にする。
- 色だけで区別しない（レーンには番号、パスは点線、など形も変える）。
- 作戦カード・作戦ボードの色と番号は紙の版とそろえる（1赤・2青・3緑・4紫、ボールはピンクのひし形）。
- iPadの縦向き・横向きのどちらでも使えるようにする。作戦ボードと動画は横向きを基本にする。
- WindowsのThinkPad（Edge）でも、タッチとマウスの両方で操作できるようにする。

## 6. 作り方（技術の方針）

- 1つのWebアプリ（HTML・CSS・JavaScript）として作り、iPadのSafariとWindowsのEdgeで開く。
- ホーム画面には追加しない前提。Safariのタブで開いたまま使う。
- 一度開いておけば、ネットがない運動場でも動くようにする（オフライン対応）。ネットにつながらない場所で最初に開くことはできないので、教室で一度開いてから運動場に出る。
- 撮影は、ブラウザのカメラ機能と録画機能を使う。iPadのSafariで撮影・再生・保存ができるかを、最初の試作で確かめる。うまくいかない場合は、iPadのカメラアプリで撮った動画をアプリに読み込む方法に切り替える。
- データ（名簿、作戦、動画、学習カード）は、端末の中のブラウザの保存領域に入れる。外のサーバーには送らない。
- PDFは、アプリの中で作る（印刷画面を使わずに、ボタン1つでファイルにする）。

## 7. 保存とプライバシー

### 決めたこと
- 保存先は**端末の中だけ**。動画も学習カードも、学校の外に出ない。
- 動画は**学期の終わり**に、先生メニューから一括で消す。
- 学習カードは**PDFで提出**し、提出したあとの端末の中のデータは、学期の終わりに消す。

### 注意：ホーム画面に追加しないときの、データの消え方
- Safariでは、ホーム画面に追加しないWebアプリのデータが、しばらく使わないと自動で消されることがある。
- 体育の授業がある週は毎回開くので消えにくいが、長い休みや単元の間が空いたときは消える心配がある。
- ブラウザの「履歴とWebサイトデータを消去」をしたときや、端末の初期化のときにも消える。

### そのための備え
1. **学習カード**：毎時間の終わりにPDFを出しておく（4.7）。提出したPDFが正式な記録になる。
2. **動画**：振り返りに使うのは主にその日のうちなので、消えても授業には大きな影響はない。先生が残したい動画は、その日のうちに写真アプリかファイルに書き出す（4.6）。
3. **名簿と作戦**：先生メニューから名簿・作戦のファイルを書き出しておき、消えたら読み込み直す。
4. アプリを開いたときに、前回の記録が見つからなければ「データが消えたかもしれません」と表示し、読み込み直しの方法を案内する。
5. 学校のiPadでホーム画面への追加ができるようになったら、追加して使う（データが消えにくくなる）。

## 8. データの形（作る人向けメモ）

```
名簿     ：児童id, 番号, 名字, 名前, ふりがな(任意), チームid
チーム   ：id, チーム名, 色, メンバー[児童id …]（人数は可変、基本5人）
設定     ：名前の表示（本名 / 名字）, ふりがなの有無, 合言葉, 学年・組
作戦カード：id, 名前, 説明文, はじめの位置{1〜4: x,y}, 動き[ {時刻, 誰, 行き先 or パス先} ]
作戦ボード：チームid, 日付, 時間目, 作戦カードid, コマの位置{児童id: x,y, 守り1, 守り2, ボール}, 書いた線[]
動画     ：id, チームid, 日付, 時間目, 作戦カードid, 長さ, 書き込み画像[]
学習カード：児童id, 単元のめあて, 記録[ {時間目, 日付, めあて, ○した番号[], できたこと, 次にやりたいこと} ], PDFを出した日時[]
```

- コートの位置は、コートの幅と長さを1としたときの割合（0〜1）で持ち、画面の大きさが変わってもずれないようにする。
- 名簿の貼り付けは、タブ区切り（Excelからのコピー）とカンマ区切り（CSV）の両方を読めるようにする。1行目が見出しかどうかは自動で判断し、確認の表で直せるようにする。

## 10. まだ決めていないこと（次に相談したいこと）

1. **アプリを置く場所**：WebアプリのURLをどこに置くか（自分で管理できる場所、学校で使えるサービスなど）。子どものデータは端末の中にしか保存しないので、置き場所に名簿や動画は入らない。
2. **名簿の写し方**：AirDropとQRコードのどちらが学校のiPadで使いやすいか。
3. **全体共有での子どもの動画**：先生の端末で子どもの動画を映したいとき、チームの端末から書き出して渡すか、チームの端末を一時的にテレビにつなぐか。
4. **PDFの提出先**：学校で使っている課題の提出の仕組み（ロイロノート、Google Classroom、Teamsなど）。
5. **iPadの設定の確認**：Safariのカメラ利用の許可、AirDropの可否、Webサイトのデータを消す設定になっていないか。
