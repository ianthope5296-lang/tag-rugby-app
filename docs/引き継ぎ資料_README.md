# トライさくせんボード（タグラグビー作戦アプリ）引き継ぎ資料

小学3年生の体育「かわして つないで トライ！」（タグラグビー）で使うWebアプリです。
iPadのSafariで、チームごとの作戦ボード・作戦アニメ・撮影と振り返り・学習カードを使えるようにします。

このフォルダは、claude.ai上で作った「試作1」を、コードの作業場所（Claude Codeなど）に移して続きを作るための資料一式です。

## まず読むもの（この順に）

| ファイル | 中身 |
| --- | --- |
| `CLAUDE.md` | コードを書くときの約束（対象端末、言葉づかい、データの扱い、やってはいけないこと） |
| `docs/実装状況.md` | 試作1で、できていること・設計書から変わったこと・わかっている課題 |
| `docs/次の作業.md` | 試作2〜4と、学校で使えるようにするまでの作業と完了の条件 |
| `docs/データ仕様.md` | コートの座標、作戦アニメのデータ、保存データ、書き出しファイル、名簿の形式 |
| `docs/設計書.md` | アプリ全体の設計書（v0.2）。授業の流れと画面の対応、保存とプライバシーの方針 |

## フォルダの中身

```
tryapp-handoff/
├─ README.md            … このファイル
├─ CLAUDE.md            … コード作業の約束（リポジトリの直下に置く）
├─ app/index.html       … 試作1。そのままブラウザで開けば動く1ファイルのアプリ
├─ prototype/artifact-source.html … claude.aiに公開した元のソース（参考。app/index.html と中身は同じ）
├─ docs/                … 設計書・実装状況・次の作業・データ仕様
├─ samples/roster_sample.csv … 名簿の読み込みを試すための架空の名簿
└─ design-ref/          … 紙の教材のデザイン（学習カード・作戦ボード・作戦カード5種）の元ファイル
```

`design-ref/` のファイルは、claude.aiのデザイン機能用の形式です。そのままブラウザで開いても表示されません。色・文言・図の座標（作戦カードのSVG）を参照するために使ってください。

## 試作1の動かし方

- `app/index.html` をChromeかEdgeかSafariで開くだけで動きます（ネットは、文字の形を読むときだけ使います）。
- 先生メニューの合言葉は、試作では `0000` です。
- 最初は、架空の名前のお試し名簿（いなずま・ひまわり）が入っています。
