トライさくせんボード　配布前の準備（先生用）

アプリのURL（iPadのSafariで開く。インストールは不要）
https://ianthope5296-lang.github.io/tag-rugby-app/

名簿・作戦・動画は、その端末のブラウザの中だけに保存されます。インターネットや学校のサーバーには送られません。公開されているのはアプリの画面だけで、子どものデータは含まれません。

1. 先生の端末で、名簿を作る（1回だけ）

  1. URLを開き、「先生」→ 合言葉 0000（はじめの合言葉）で入る。
  2. 「名簿の登録」：Excelで「番号・名字・名前・チーム」の4列をコピーして貼り付け →「読み取る」。CSVファイルも読み込めます。
  3. 下の表でチーム名・色・メンバーを確かめて「この名簿で保存する」。「名前の表示」（本名／名字だけ）も選ぶ。
  4. 「ファイルに書き出す」で tryapp_日付.json を保存（ファイルAppの「ダウンロード」に入ります）。これが各iPadへ配る名簿になり、データが消えたときの備えにもなります。

2. 子どもが使う各iPadで（1台ずつ）

  1. SafariでURLを開く（QRコードをカメラで読む）。プライベートブラウズではないタブで開く。
  2. 名簿ファイル（json）をAirDropなどでそのiPadに送る →「先生」→「ファイルを読み込む」で選ぶ。
  3. 「先生の合言葉」を変える（数字4〜8けた）。合言葉は端末ごとで、名簿ファイルには入りません。はじめの「0000」のままだと、先生メニューに赤い注意が出ます。
  4. カメラの許可：チームを選び「どうがを とる」を一度おして「許可」。毎回たずねられる場合は「設定」→「アプリ」→「Safari」→「カメラ」を「許可」にする。
  5. ネットがなくても開けるように、教室で2回開いておく（再読み込みを1回）。運動場では、そのタブを閉じない。
合言葉を変える前に、子どもに渡さないでください。先生メニューからは、名簿の入れ替えや動画の一括消去ができます。

3. 学校の管理者に確かめておくこと

  • Safariのカメラ利用が許可されているか（MDMで止められていないか）。
  • 終了時に「履歴とWebサイトデータ」が自動で消える設定や、プライベートブラウズの強制になっていないか（なっていると、作戦や動画が消えます）。
  • 空き容量：動画は10分で約150MB。空きが少ないと撮影画面に知らせが出ます。

4. 授業での使い方

場面操作
作戦タイム「チームで つかう」→ チーム → 作戦ボード。作戦カードを貼り、アニメで確かめ、コマや線で話し合う。「今日の さくせんを ほぞん」で時間目と一緒に保存。
ゲーム（撮影）作戦ボードの「どうがを とる」。撮影係が赤いボタンで開始・停止（10分で自動停止）。チーム・日付・時間目・貼っていた作戦が自動で付きます。
振り返り「ふりかえり どうが」→ 動画を選ぶ → 速さを変えて再生。「さくせんと ならべて 見る・かきこむ」で作戦アニメと並べ、止めた画面に「走る・パス・ふり・まる・ボール」を書き込み、画像として保存。

5. データの扱い

  • 残したい動画・画像は、その日のうちに「しゃしんAppや ファイルに ほぞん」（共有シートの「ビデオを保存」「画像を保存」）。
  • 名簿・作戦の控え：先生メニュー「ファイルに書き出す」（動画は入りません）。
  • 学期の終わり：各iPadの先生メニュー「動画をすべて消す」（2回おす。書き込み画像も消えます）。写真Appに保存したものは、写真Appで別に消してください。

6. 困ったとき

こんなときこうする
カメラが映らない「設定」→「アプリ」→「Safari」→「カメラ」を「許可」。だめなら撮影画面の「カメラアプリの どうがを 入れる」で、カメラアプリで撮った動画を入れる。
運動場で開けない教室（ネットのある所）で開き直し、再読み込みを1回してから外へ。
名簿や作戦が消えた先生メニュー「ファイルを読み込む」で、書き出したjsonを読み込む。
画面が古いまま一度再読み込みすると、次に開いたときに新しい版になります。
合言葉を忘れた戻す方法はありません。「設定」→「アプリ」→「Safari」→「詳細」→「Webサイトデータ」でこのサイトのデータを消すと、はじめの状態（合言葉0000）に戻ります。その端末の名簿・作戦・動画も消えるので、名簿は書き出したjsonから入れ直してください。

まだ使えないもの：学習カード（ホームのボタンは「もうすぐ つかえます」と表示）。
