さつえいと ふりかえりの しかた

3年 体育「かわして つないで トライ！」　（iPadの「カメラ」と「しゃしん」を つかいます）

さくせんを きめる

かみの さくせんカードと さくせんボードで、だれが どこに 立って、どう 走るかを きめよう。

どうがを とる（さつえい がかり）

1「カメラ」を ひらいて、下の もじを「ビデオ」に する。

2コート ぜんたいが うつるように もつ。iPadは よこ むきに する。

3赤い ボタンで はじめる。もう一ど おすと とまる。

ふりかえる

1「しゃしん」を ひらいて、とった どうがを えらぶ。▶で 見る。

2大じな ところで とめる。下の こまを ゆびで ゆっくり うごかすと、すこしずつ 見られる。

3スクリーンショットを とる：上の ボタン と ホームボタン を いっしょに おす
　（ホームボタンが ない iPadは 上の ボタン と 音を 大きく する ボタン）

4左下に 出た 小さな しゃしんを すぐ タッチ → ペンで やじるしや まるを かく。
　走る は 黒い 線、パスは ピンク、ふりは はいいろ で かこう。

5「かんりょう」→「"しゃしん"に ほぞん」。

やくそく

  • どうがは、タグラグビーの じかんだけ とる。「とっても いい？」と きいて から とる。
  • とった どうがや しゃしんは、チームの なかまと 先生だけで 見る。ほかの 人に おくったり、インターネットに のせたり しない。
  • どうがや しゃしんは、かってに けさない。こまったら すぐに 先生に 言う。
