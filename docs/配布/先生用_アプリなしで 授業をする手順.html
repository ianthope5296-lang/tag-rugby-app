アプリが使えるまでの授業の手順（先生用）

学校のフィルターでアプリ（github.io）が開けない間は、紙の教材と、iPadに最初から入っている「カメラ」「写真」で同じ流れを行います。

1. 授業の前に（各チームのiPad）

  • iCloud写真がオフかを確かめる（「設定」→ 上の名前 →「iCloud」→「写真」）。オンだと、撮った動画が学校の外のクラウドに上がります。管理者の設定で決まっている場合は、管理者に確認してください。
  • 画質を下げて容量を節約する：「設定」→「カメラ」→「ビデオ撮影」→「720p HD/30 fps」。10分で数百MB使うので、空き容量も確かめる（「設定」→「一般」→「iPadストレージ」）。
  • AirDropを「受信しない」か「連絡先のみ」にしておくと、動画が他の端末に送られる心配が減ります。
  • 紙の作戦カード（5種）と作戦ボードを、チームの数だけ用意する。

2. 授業の流れ

場面すること
作戦タイム紙の作戦カードを作戦ボードに貼り、立ち位置と動きを話し合う。
ゲーム（撮影）撮影係が「カメラ」の「ビデオ」で撮る（iPadは横向き、コート全体が入るように）。1本は1ゲーム分を目安に、短めに区切る。
振り返り「写真」で動画を見る。止めたい場面で一時停止し、下のコマを指で動かして少しずつ確かめる。
書き込みスクリーンショット（上のボタン＋ホームボタン。ホームボタンがない機種は上のボタン＋音量を上げるボタン）→ 左下のサムネイルをタップ → ペンで矢印や丸を書く →「完了」→「"写真"に保存」。走る＝黒、パス＝ピンク、ふり＝灰色にすると、作戦カードとそろいます。「＋」の「図形」で、きれいな矢印や丸も入れられます。

スローで見たいときは、カメラを「スロー」にして撮ると、写真Appでゆっくり再生されます（その分、容量が増えます）。

3. データの扱い

  • 動画と書き込み画像は、そのiPadの「写真」に入ります。チームの子どもと先生だけで見るよう指導します（子ども用の紙の「やくそく」）。
  • 学期の終わり：「写真」で動画と画像を選んで削除し、さらに「最近削除した項目」からも削除する（ここを消さないと30日間残ります）。

4. アプリが使えるようになったら

  • アプリの撮影画面「カメラアプリの どうがを 入れる」から、写真Appの動画を取りこめます。取りこむ前に、作戦ボードで「今日の さくせん」と「何時間目」を合わせておくと、その情報が動画に付きます（日付は取りこんだ日になります）。
  • 取りこんだあとは、写真Appの元の動画は消してかまいません。
