# データ仕様

## 1. コートの座標
- 幅400 × 高さ560 の固定の座標（SVGの `viewBox="0 0 400 560"`）。画面では割合（%）で置く。
- y=0〜60：トライゾーン。y=110：まもりのスタートライン。y=480：スタートライン。y=480〜560：コートの外（監督・控え）。
- レーンの中心 x：1=50、2=150、3=250、4=350。スタートでの攻めの位置 y=452。控えの位置 y=508（5人目以降は y=540）。
- 上（yが小さい方）へ向かって攻める。パスは後ろ（yが大きい方）か真横にだけ出す。

## 2. 作戦アニメ（`CARDS`）

```js
{
  id: 'reverse',            // 作戦のid（cross, fake, skip, reverse, loop）
  no: 4, name: 'ぎゃくに！', color: '#a8326e',
  desc: '…子ども向けの説明文…',
  carrier: 3,               // 最初にボールを持つ立ち位置の番号
  path: {                   // 動く人ごとの通過点 [秒, x, y]（なめらかな曲線でつなぐ）
    1: [[0,50,421],[1.6,50,380]],
    2: [...], 3: [...], 4: [...],
    d1: [...], d2: [...]    // まもり2人
  },
  passes: [{t0:3.3, t1:3.9, to:2}],          // パス：t0に投げて、t1に「to」の人が受ける
  fakes:  [{t0:1.6, t1:2.8, from:3, to:4}],  // ふり：fromがtoの方へボールを伸ばして戻す（省略可）
  bubbles:[[開始秒, 終了秒, '動く人のキー', '吹き出しの文']], // 省略可
  caps:   [[開始秒, '字幕']]                  // 下の字幕。最後のものが表示され続ける
}
```

- 同じ点が2つ続くと、その間は止まる（例：`[0,150,310],[0.6,150,310]`）。
- アニメの長さは、最後の通過点・パス・字幕の時刻＋1秒。
- 手の動き（パス・ふり）は `passes` と `fakes` から自動で決まる（`actions()`）。

## 3. 作戦の矢印（`PLANS`）
- 作戦ごとの、紙のカードのようなシンプルな矢印。アニメの止まっている画面と、作戦ボードの「お手本の線」に使う。
- `{type:'run'|'pass'|'fake', pts:[[x,y], ...]}`。点が2つならまっすぐ、3つ以上ならゆるいカーブ（2次ベジェ）。

## 4. 端末の中の保存データ（`localStorage` のキー `tryapp.v1`）

```js
{
  roster: { teams: [ { id, name, color, members: [ {id, no, sei, mei} ] } ] },
  settings: { nameMode: 'full'|'sei', pin: '0000', sample: true|false },
  boards: {            // チームごとの、今のボードの状態
    [teamId]: {
      card: 'cross'|null,      // 貼っている作戦（オリジナルのもとの作戦）
      blank: true|false,       // まっさらから作っているとき
      origId, origName,        // 呼び出し中・作成中のオリジナル作戦
      showBase: true|false,    // お手本の線を見せるか
      assign: {'1':memberId, '2':…, '3':…, '4':…, 'k':監督のmemberId},
      pos: { [memberId]:[x,y], d1:[x,y], d2:[x,y], ball:[x,y] },
      holder: memberId|null,   // ボールを持っている人
      lines: [ {type:'run'|'pass'|'fake', pts:[[x,y],…]} ],  // 子どもがかいた線
      period: 1〜8
    }
  },
  saved: { [teamId]: [ {id, at:'10/25 16:04', period, card, assign, pos, lines, holder} ] },  // 今日の作戦（最大30件）
  originals: { [teamId]: [ {id, name, base:'cross'|null, assign, pos, lines, holder} ] }    // オリジナル作戦
}
```

- 試作2以降の動画は、`localStorage` ではなく IndexedDB に入れる（容量のため）。
- 学習カードのデータの形は、設計書8章の「学習カード」を使う。

## 5. 書き出しファイル（JSON）
- ファイル名：`tryapp_YYYYMMDD.json`
- 中身：`{app:'tryapp', v:1, exportedAt, roster, settings:{nameMode}, saved, boards, originals}`
- 読み込むときは `app==='tryapp'` と `roster.teams` があることを確かめる。名簿・作戦・オリジナルを置き換える。

## 6. 名簿（コピー＆ペースト・CSV）
- 4列：番号, 名字, 名前, チーム（例：`samples/roster_sample.csv`）。
- 区切りはタブ（Excelからのコピー）かカンマ（CSV）。`"…"` で囲んだ値も読める。
- 1行目に「番号・名字・姓・名前・チーム・氏名」のどれかがあれば、見出しとして読み飛ばす。
- 3列で1列目が数字でないときは「名字, 名前, チーム」として読む。
- チーム名ごとにチームを作り、色は順番に割り当てる（あとで先生メニューで変えられる）。
